# SWYNEX Task 4 – Final Bioinformatics Report

## 1. Introduction
Bioinformatics is the application of computer science and biology to analyse biological data.

In this project, we analyse the SARS-CoV-2 reference genome using bioinformatics concepts.

## 2. Dataset Description
- Organism: SARS-CoV-2
- Genome type: RNA
- Database: NCBI
- Accession Number: NC_045512.2
- Genome length: Approximately 29,903 nucleotides.

## 3. Research Question
What are the important characteristics of the SARS-CoV-2 genome, and how can bioinformatics tools help in analysing its sequence?

## 4. Objective
- To study the SARS-CoV-2 genome.
- To understand DNA/RNA sequence analysis.
- To identify important genomic features.
- To understand the applications of bioinformatics.

## 5. Methodology
1. Selected the SARS-CoV-2 reference genome from NCBI.
2. Retrieved the reference sequence using its accession number.
3. Studied the genome sequence and its features.
4. Analysed the biological information.
5. Interpreted the findings.

## 6. Results and Analysis
The SARS-CoV-2 reference genome contains approximately 29,903 nucleotides.

It is a positive-sense single-stranded RNA virus.

The genome contains important genes responsible for viral replication and structural proteins.

## 7. Interpretation
Bioinformatics helps researchers understand viral genomes and identify important genetic features. Genome analysis is useful in studying viral evolution, mutations and disease research.

## 8. Limitations
- Analysis depends on the quality of the reference sequence.
- Further experimental validation may be required.
- Genome analysis alone cannot explain every biological function.

## 9. Conclusion
This project helped us understand how bioinformatics is used to analyse viral genome sequences. The SARS-CoV-2 reference genome provides useful information for genomic research.
